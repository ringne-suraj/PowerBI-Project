# 🥤 Coca-Cola Sales Dashboard (Project III)

## 📌 Overview
This Power BI dashboard analyzes Coca-Cola sales data to track performance, trends, and key business metrics for better decision-making.

## 🎯 Objective
- Monitor overall sales performance  
- Analyze region-wise and product-wise sales  
- Identify top-performing segments  
- Visualize trends using interactive dashboards  

## 🛠️ Tools Used
- Power BI  
- Excel  
- GitHub  

## 📈 Key Insights
- Highlighted top-performing regions and products  
- Identified sales trends over time  
- Enabled quick performance comparisons
